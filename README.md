# 日语50音图训练系统

学习日语的第一步是掌握50音图，这是日语发音的基础，也是学习日语的必经之路。通过该训练系统，每天花5到10分钟进行集中练习，您将有效掌握平假名与片假名的认读与发音规则，并逐步提高反应速度和熟练程度。

## 功能特点

- 支持平假名和片假名的练习
- 实时反馈和评分系统
- 薄弱环节分析报告
- 多种练习模式（计时/不限时）
- 详细的练习统计

## 使用方法

1. 选择要练习的假名（平假名/片假名）
2. 选择练习时间（3分钟/5分钟/10分钟/不限时）
3. 开始练习，输入对应的罗马音
4. 练习结束后查看详细报告

## 评分标准

- 基准：60分 = 每分钟正确辨识100个假名，错误5个以内
- 正确率占70%，错误率占30%
- 优秀：≥90分
- 良好：80-89分
- 合格：60-79分
- 不及格：<60分

## 评分算法说明

评分系统基于以下原则设计：
1. 正确率权重为70%，错误率权重为30%
2. 基准成绩60分对应每分钟正确输入100个，错误控制在5个以内
3. 错误数超过基准会逐渐扣除更多分数：
   - 错误在5个以内：不扣分
   - 错误在6-10个：每个多扣2分
   - 错误超过10个：每个多扣3分
4. 评分符合正态分布原则，90分以上的人群约占10%

## 速度计算说明

当前输入速度的计算基于以下原则：
1. 记录连续两次正确输入之间的时间间隔
2. 通过时间间隔计算每分钟可能的正确输入数
3. 使用移动平均算法平滑波动，当前速度 = 旧速度 × 0.7 + 新速度 × 0.3
4. 只有正确输入才会更新速度，错误输入不影响速度计算

## 自定义与扩展

如需添加更多假名或修改现有假名，可以编辑script.js文件中的`hiraganaData`和`katakanaData`数组。假名按行分组排列，便于学习和选择。
